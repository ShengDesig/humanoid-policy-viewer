# G1 SysID Viewer Windows portable package

This packaging path produces a ZIP that a Windows user can run without installing Node.js, npm, Python, or a development environment.

## Package contents

```text
G1-SysID-Viewer-Windows-x64/
├── Start-G1-SysID-Viewer.cmd
├── README.txt
├── THIRD_PARTY_NODE_LICENSE.txt
├── runtime/
│   ├── node.exe
│   └── portable-server.mjs
└── site/
    ├── index.html
    ├── assets/
    ├── examples/
    └── motions/default.json   # optional
```

The included server binds only to `127.0.0.1`. It is not reachable from other computers and does not require a firewall exception.

## Build a package with the current motion

Run from the repository root on Windows PowerShell:

```powershell
.\scripts\package-windows-portable.ps1 -MotionJson "C:\work\g1_systemID-viewer\build\humanoid-policy-viewer\motions\default.json"
```

The output is:

```text
artifacts\G1-SysID-Viewer-Windows-x64.zip
```

The bundled motion is loaded automatically when the colleague starts the viewer.

To start playback automatically as well:

```powershell
.\scripts\package-windows-portable.ps1 -MotionJson "C:\work\g1_systemID-viewer\build\humanoid-policy-viewer\motions\default.json" -Autoplay
```

## Build a generic package

A generic package does not contain experiment data. The user loads an exported motion JSON with the file picker.

```powershell
npm.cmd run package:windows
```

or:

```powershell
.\scripts\package-windows-portable.ps1
```

## Colleague workflow

1. Extract the ZIP completely.
2. Double-click `Start-G1-SysID-Viewer.cmd`.
3. Keep the command window open while the viewer is in use.
4. Close the command window to stop the local server.

The launcher opens the browser automatically. If the default port is occupied, the server selects a nearby available port.

## GitHub Actions artifact

The `Windows portable package` workflow builds a generic ZIP and uploads it as the `G1-SysID-Viewer-Windows-x64` artifact. It deliberately excludes local motion recordings so experiment data is not published accidentally.

## Data boundary

The portable viewer consumes the validated JSON generated by `g1_systemID/scripts/export_viewer_motion.py`. Raw NPZ parsing remains outside the browser for V1.
